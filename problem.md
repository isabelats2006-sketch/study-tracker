# Problem

I have been trying to study for my CSC 300 final and I have a certain amount of hours I want to hit daily of study, but I keep losing track of how many hours Ive actually been getting everyday and I feel like Im falling short on my studying. I could set up better alarm or organize myself better, but Im stressed, finals week is coming, Im part of the VB team and I have BIG EAST post season games coming up, it would be much easier if I had a program that did the hard work for me so that I could focus on the actual studying and be able to see how far away I am from my goals without much effort (so that my energy can go where its most needed). Just to be clear, I wouldnt place any info concerning my VB team or stuff related to that, but this is an actual problem Im going through and this an application that can be used by any student in need of efficient organizing.

# Initial requirements

- It will keep track of the hours studying and the sessions.
- Sessions do not have to be daily, there can be multiple session a day.
- It should be done in the browser and it would look almost like a file/folder "relationship". What I mean by that is that, the main information presented once the program starts is that days that studying has been logged, and how long in total study hours that day had.
- If you click on that day you can see the specifications, such as how many sessions there were, when they started (time wise, it should be the machine time; i.e. if ur PC is in CT time, it should be CT time), how long they lasted and when they ended.
- The person can set up goals, the goal is set the very first time the program is ever run and can be changed at any time.
- Days that dont have any hours logged still show up. They show up from the moment a goal is started and a new goal (same for the very first goal) starts at 0, and only the user can reset it.
- If no goal is set (in other words, if the goal is 0) then all days fall within the goal (the program has a little easter egg where it says have a great off day!! at the top, if there is a goal bigger then 0, it should say, time to work hard!!).
- Also, the program should say how many hours youve done and how far away you are from your goal, percentage wise. So if I need to do 10 hours and have done 4 hours alr, it should say 40% completed.
- To make a study session you must click on the day and click on add a session. After that, there will be two options, one to start the clock and the second one to manually add an amount of hours/minutes (in that way, if the user forgot or didnt have access to the PC, they can still add hours to the past days). If the browser tab is closed while the clock is running, the session is saved up to the moment it was closed.
- It should save progress too and if the user wants to reset, it has to manually reset it, even if the goal is completed or the deadline is met, the user is the only one who can reset anything. That means that if the user goes over it, a new interface is added that says, extra hours or for deadlines, it should say, X time (in hours, minutes or days) past deadline. If the goal is not met, its should also have an small interface where it says the past goal agaisnt the amount fo hours done. So in our example (4 hours of 10, weekly goal), if monday comes and ive only done those 4 hours it should say, past week* = 4/10 hours* (do note the *, it means that its dependent on the users choice, if the goal is 45min, it should be 45min, not 0.75 hours, same for week, if the goal is daily, it should say past day). If no hours were done or its the first entry, it should say 0.
- The user can also place deadlines, but that is optional, if they do choose to do that, there will be a countdown for the day. The countdown shows how many days are left until the deadline, at the top of the page.
- The goal placed can be a daily goal or a weekly goal or even monthly/yearly. When the user in placing the goal it will be a box with these options and the user should choose one
